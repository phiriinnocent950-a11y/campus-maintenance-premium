# CampusCare — Campus Maintenance Requests (V2.0)

A polished, responsive Activity 6 frontend for the Mulungushi University ICT251 Web Technologies assignment.

## Run the project

1. Extract the ZIP file.
2. Open the `campus-maintenance-premium` folder in Visual Studio Code.
3. Run `index.html` with the VS Code **Live Server** extension.
4. Use the navigation to explore Overview, Manage Records and About.

A local web server is recommended because the JavaScript files use ES modules. You can also deploy the folder as a static site to Netlify.

## Features

- Responsive dashboard with maintenance summary cards.
- Create, view, edit and delete maintenance records.
- Confirmation before deletion.
- Search requests by title and filter by status.
- Result count and clear success/error feedback.
- Eight fictional starting records.
- Browser persistence using `localStorage`.
- Accessible labels, keyboard focus states and responsive layouts.
- Data service kept separately in `js/data.js` for the later backend activity.

## Assignment data structure

Each record uses the required fields only:

`id`, `title`, `category`, `description`, `status`

Allowed statuses: `Pending`, `In progress`, `Completed`.

The ID is generated by the data service and is not editable. Text is trimmed before validation. An empty saved array remains empty after refresh.

## Before submitting

1. Open `index.html` and test add, view, edit, cancel edit, delete, search, filter and refresh.
2. In the About section, replace **ADD YOUR STUDENT NUMBER** with your actual student number. This is intentionally a placeholder because your number was not provided.
3. Keep your Activity 6 hosted frontend URL for marking.
4. Activity 6 uses browser demonstration data only. It does not include a backend, database, login, online payments or file uploads. Activity 7 introduces the independent Node.js backend; Activity 8 connects the frontend to it.
5. For Activity 8, configure the backend base URL in `js/config.js` and adapt the data service methods to call the API while keeping the same method names.
